# 回望 Peak — 台股觀察室

純 HTML / CSS / JavaScript，無框架、無建置步驟、無後端。適合 GitHub Pages（含 repository 子路徑）。

## 發布到 GitHub Pages

1. 在 GitHub 建立一個 repository，例如 `stock-watch`。
2. 將這個資料夾裡的所有檔案上傳到 repository 根目錄，保留檔名與相對位置。不要只上傳 index.html；PWA 還需要 sw.js、manifest 與圖示。
3. 進入 repository 的 **Settings → Pages**，在 Build and deployment 選 **Deploy from a branch**，選擇 **main / (root)** 並儲存。
4. 等 GitHub 部署完成後，開啟 `https://你的帳號.github.io/stock-watch/`。使用 GitHub 顯示的實際網址。
5. 網站「API 設定」可填入自己的 FinMind Token。請勿把個人 Token 寫進公開程式碼或上傳到 GitHub。

直接雙擊 index.html 可以查看介面，但請透過 HTTPS 或 localhost 使用正式功能。file:// 的 localStorage 行為依瀏覽器而異，且不支援完整 PWA／通知功能。

## 使用

- 輸入例如 `2330`，按「加入觀察」。先以 `TaiwanStockInfo` 驗證股票，再儲存至 localStorage。同日股票總覽會快取；不存在的代碼不加入。
- 年數為 1–100 的整數，表示從台北日期往前回推指定年數（處理閏日），取 `TaiwanStockPrice.max` 的最大值。上市未滿指定年數則以實際可取得的歷史計算，卡片顯示資料起始日。
- 回落幅度 = `(區間最高價 − 最近價格) / 區間最高價 × 100`。
- 最高 500 元、門檻 20%：最近價 ≤ 400 元即達標。達標卡片會顯示綠色。
- 當年數變更時，會重新抓取完整區間；尚未取得完整區間不顯示可能誤導的歷史高點，也不發送提醒。
- Token 預設僅放在分頁記憶體；重新整理後需再次輸入。只有勾選「記住 Token」才放進 localStorage。

## 日線與即時模式

每張股票卡片另顯示 **本益比（公布值）**、**近四季 EPS（原始加總）**，附本益比日期與四季明細。資料來源分別為 FinMind `TaiwanStockPER.PER` 與 `TaiwanStockFinancialStatements` 的 `type=EPS`。本益比使用最近一筆公布值，不以盤中股價重新計算；0、負值或無資料時顯示「—／不適用」。

EPS 只加總最近四個連續季度，保留負數與零；缺季、半年報或不足四季時顯示資料不足，不以零補齊。各季為原始基本 EPS，未依配股／分割調整歷史股數，可能與公司追溯調整後的 TTM EPS 不同，不能直接據此推算精確本益比。查詢近三年財報以涵蓋可用的四季；ETF 等無企業 EPS 資料時顯示「—」。

基本面資料及最近查詢日會一併儲存在本機，每個台北日期自動查詢一次（每檔增加兩次 API 請求），不隨 30 秒股價輪詢重抓。按「手動更新」會重新查詢；失敗時保留原值、原資料日期並顯示錯誤，隔天或手動更新再重試。原有股票可按手動更新補上基本面資料。

`e2e-live-5s.html` 維持每 5 秒更新假行情，模擬本益比 18.5 倍、單季 EPS 8／9／10／11 元，合計 38 元；0050 模擬無企業基本面資料。`e2e-tests.html` 加入本益比日期、EPS 加總與缺季顯示的瀏覽器測試。兩者均不查詢真實 FinMind 資料。

**日線模式**：使用 FinMind 免費 `TaiwanStockPrice`。最近價是最近有效交易日收盤價，並顯示日期；不是盤中即時價。官方文件說明通常在交易日 17:30 更新，實際以 API 資料為準。休市或盤後可按「手動更新」取得最新可用收盤價。

**即時模式**：使用 `taiwan_stock_tick_snapshot`，需有 FinMind sponsor 權限的 Token。每次輪詢透過 repeated `data_id` 參數批次查詢觀察標的，歷史日線同日快取，避免每 30 秒下載多年歷史。即時資料未取得或當日無有效成交時，回退至最近日線並註明。API 權限仍受使用者方案及 FinMind 規定限制。

官方目前記載：無 Token 每小時 300 次、有 Token 每小時 600 次，實際依帳號方案。日線模式每檔約 120 次／盤中小時，另有歷史與代碼驗證請求；多檔可能超額。即時批次模式正常約 120 次／小時，另加歷史請求。股票儲存數量沒有額外人為上限，但 API 額度與本機容量仍會限制實際可用量。建議只開一個分頁，其他網站與分頁亦可能共用 API 額度。

API 回傳 402／429 時停止查詢 60 分鐘；401／403 暫停 5 分鐘。修正 API 設定並儲存可重置冷卻時間。失敗會保留先前資料並顯示訊息，不會偽造即時報價。

## 開市與休市

- 以 Asia/Taipei 判斷時間，週一至週五 09:00 ≤ 時間 < 13:30 每 30 秒更新。
- 開頁時載入 TWSE 官方年度休市表，正常交易日備註不列入休市日；內建已核對的 2026 年休市表作為離線／CORS 失敗備援。
- 使用同年度已快取的休市表；若跨年度沒有可用日曆且官方來源連線失敗，會停止自動查詢並提示，仍可手動更新。跨年度請重新開頁以載入新日曆。
- 天災臨時休市不一定出現在年度表中，請在「本機備份與休市日曆」自行補充；瀏覽器無法僅憑年度表保證辨識所有臨時停市。
- 週末、休市、盤外與離線時不自動呼叫 FinMind。加入標的、匯入驗證與手動更新屬於使用者主動查詢，仍可在這些時段執行。
- 自動更新限開啟中的頁面；背景分頁、手機休眠與省電模式可能延遲計時，不能保證背景每 30 秒。

## 通知與 PWA

Android／手機通知統一使用 `ServiceWorkerRegistration.showNotification()`，不使用手機可能禁止的原生 `new Notification()`。正式版、三則真實通知測試按鈕及 5 秒假行情系統通知均適用。請一併上傳 `sw.js`，並以 GitHub Pages HTTPS 網址開啟；本機 file:// 仍可查看假行情與模擬通知紀錄，但無法驗證此系統通知通道。

若手機出現「Illegal constructor」表示仍載入舊測試頁，請完成更新後重新整理，或於網址後加上 `?v=3` 再試。三則測試通知可能被 Android 分組，請展開通知列查看；API 發送成功不保證系統一定顯示橫幅。

- 先點「開啟瀏覽器通知」授權；達門檻時發送瀏覽器／系統通知。實際是否顯示仍受作業系統、勿擾模式、網站權限影響。
- 每次進入達標狀態只提醒一次；回升到門檻上方後再跌回會重新提醒。改變年數或門檻會重新判斷；授權時已達標也會通知。
- 已抓取資料的日期會寫入通知，避免把過去收盤價當成當下成交。
- Chrome／Edge 可使用安裝圖示或瀏覽器「安裝應用程式」；iPhone／iPad 請以 Safari「加入主畫面」，從主畫面開啟再要求通知（需支援 Web Push 的系統版本，通常為 iOS/iPadOS 16.4+）。瀏覽器是否允許安裝由它的規則決定。
- Service Worker 只快取同來源的公開介面及圖示，不快取 FinMind 回應與 Token。離線可讀取本機觀察清單及歷史價格。
- **關閉頁面後不查價、不主動通知**。靜態 GitHub Pages 無法提供全天候背景每 30 秒監控；此需求需要後端排程與 Web Push 服務，超出純靜態檔案能力。
- 更新版本時同步調整 sw.js 的 `CACHE` 版本，確保離線介面更新。

## 儲存與備份

localStorage 儲存股票、年數、提醒門檻、價格快取、提醒狀態與休市日期。容量上限由瀏覽器決定，不以 cookie 的小容量限制清單。會捕捉讀寫與額滿錯誤，新增標的寫入失敗時回復新增操作。清除網站資料、無痕模式或瀏覽器重設會造成資料消失；不同網址／瀏覽器／裝置不會同步。

「匯出清單」包含代碼、名稱、年數、門檻與補充日期，不含 Token 和歷史股價；「匯入清單」會向 FinMind 驗證代碼並合併標的，保留目前頁面的年數、門檻及補充日期。匯入後請手動更新。

## 原始資料與限制

- 價格採未還原股價，除權息／分割可能造成回落幅度失真。不同上市期間及資料可用性會影響高點範圍。
- 股價為 0 或無有效成交的日線會排除，避免零價格誤報。
- 瀏覽器直接連 FinMind 及 TWSE，服務端若改變 CORS、API 格式或授權政策，需相應調整；不使用公開 CORS proxy。
- 已透過 Node 模擬環境驗證計算、休市邊界、通知去重／重啟、Token 儲存選項、API 額度冷卻與 localStorage 額滿路徑。此製作環境無法連至本機預覽，因此尚未完成真實瀏覽器視覺、FinMind 帳號授權及裝置通知測試。請部署後以自己的 Token 驗證。
